# API для Yatube (Yatube API)

## Описание
Yatube API — это RESTful API для социальной сети Yatube, разработанное на базе Django Rest Framework (DRF). Проект предоставляет программный интерфейс для взаимодействия с платформой блогов. 

### Основные возможности и польза проекта:
* **Публикации и комментарии**: Чтение, создание, обновление и удаление постов и комментариев к ним.
* **Сообщества**: Просмотр доступных групп и информации о них.
* **Система подписок**: Возможность подписываться на любимых авторов и искать по своим подпискам.
* **Безопасность и права доступа**: Аутентификация реализована с помощью JWT-токенов (библиотека Djoser). Анонимные пользователи имеют доступ к контенту только в режиме «чтение» (кроме подписок — они полностью закрыты от анонимов). Изменять и удалять контент могут исключительно его авторы.

### Как запустить проект:

Клонировать репозиторий и перейти в него в командной строке:

git clone https://github.com/vanionikas/api-final-yatube-ad.git

```
cd api_yatube  
```

Cоздать и активировать виртуальное окружение:
```
python3 -m venv env  
```
```
source venv/bin/activate  
```

Установить зависимости из файла requirements.txt:
```
python3 -m pip install --upgrade pip  
```
```
pip install -r requirements.txt  
```

Выполнить миграции:
```
python3 manage.py migrate  
```

Запустить проект:

python3 manage.py runserver


## Примеры запросов к API

Все запросы к API должны начинаться с префикса `/api/v1/`.

### 1. Аутентификация (Получение JWT-токена)
* **POST** `/api/v1/jwt/create/` — передайте `username` и `password` в формате JSON,
* чтобы получить `access` и `refresh` токены.
* Пример тела запроса:
```json
{
  "username": "auth_user",
  "password": "secure_password123"
}
